Build Odoo from source

Pick your Odoo version and Linux distribution, and get one bash script that clones Odoo Community, builds a virtualenv, writes the config and optionally sets up PostgreSQL and a systemd service. It all runs in this page: nothing is sent anywhere and there is no analytics.










Read the script before you run it: it uses sudo, creates a system user and writes under /opt or your home folder. Odoo is a trademark of Odoo S.A.; this page is an independent tool.
